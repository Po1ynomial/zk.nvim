SETUP                                                              *zk-setup*

The plugin requires Neovim 0.12 or newer and the `zk` executable.

Configure a personal archive to make archive commands available from every
buffer: >lua

  require("zk").setup({
    archive = "~/zettelkasten",
  })
<
The default language-server command is `{ "zk", "lsp" }`. The default CLI
command is `{ "zk" }`. Override either when `zk` is not on $PATH: >lua

  require("zk").setup({
    lsp_cmd = { "/path/to/zk", "lsp" },
    cli_cmd = { "/path/to/zk" },
  })
<
The `archive` option expands `~` and environment variables, resolves relative
paths against Neovim's current working directory, and validates the archive
before selecting it. The canonical selected path is readable as
`require("zk").archive`.

The configured archive starts one background `zk` language server during
setup. A nearer `zk.toml` above the current buffer takes precedence and gets
its own server when needed. Without `archive`, the plugin retains local-only
discovery.

Tinymist can remain attached to the same Typst buffer. The plugin makes
`zk.toml` a higher-priority Tinymist root marker than `.git`, so imports from
`../lib/` work even when the archive is not a Git repository.

Set `decorations = false` to disable title extmarks. Set `mappings = false` to
disable all default mappings. Individual mapping values can also be replaced
or set to `false`.

==============================================================================
COMMANDS                                                        *zk-commands*

:ZkFind [query]                                      *:ZkFind*
    Search live Zettel metadata in the selected archive through
    `workspace/symbol` and present the results through |vim.ui.select()|.

:ZkBacklinks                                         *:ZkBacklinks*
    Put all incoming authored reference locations for the current Zettel into
    the quickfix list.

:ZkDiagnostics                                       *:ZkDiagnostics*
    Put diagnostics from the selected `zk` language server into quickfix.

:ZkCheck                                             *:ZkCheck*
    Run `zk check` against saved archive state.

:ZkNew                                               *:ZkNew*
    Run `zk new`, then edit the generated Zettel.

:ZkRemove [ID]                                       *:ZkRemove*
    Run guarded removal for ID, or for the current Zettel when ID is omitted.

:ZkRefresh                                           *:ZkRefresh*
    Refresh title decorations in the current buffer.

:ZkSetArchive [path]                                 *:ZkSetArchive*
    Select another fallback archive for this Neovim session. Invalid paths
    leave the existing fallback and server unchanged. With no path, report
    the current fallback.

ZkFind, ZkNew, ZkCheck, ZkDiagnostics, and ZkRemove with an explicit ID work
from any buffer when a fallback is configured. ZkBacklinks, ZkRefresh, and
ZkRemove without an ID require a current Zettel.

==============================================================================
MAPPINGS                                                        *zk-mappings*

The defaults are buffer-local:

  gd              Follow a Zettel reference with `zk lsp`; use normal LSP
                  definition elsewhere.
  <leader>zf      Search Zettel.
  <leader>zb      Show backlinks.
  <leader>zd      Show Zettelkasten diagnostics.
  <leader>zn      Create a Zettel.

==============================================================================
DECORATIONS                                                  *zk-decorations*

Resolved `@ID` ranges are concealed and replaced with target-title virtual
text. Missing targets use the `ZkMissingReference` highlight. The raw source
remains unchanged and becomes visible according to Neovim's conceal rules.

Decorations come from `zk lsp` queries. The Lua plugin does not parse Typst or
keep an archive graph.
